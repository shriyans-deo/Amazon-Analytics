# Amazon Sales Dashboard (Excel)

## Overview

This project is an interactive Amazon Sales Dashboard developed in Microsoft Excel using a dataset of 100,000+ sales records. The dashboard provides key business insights through KPI cards, dynamic visualizations, and slicer-based filtering.

## Features

* KPI Cards

  * Total Revenue
  * Total Orders
  * Total Quantity Sold
  * Average Order Value (AOV)
  * Delivered Orders %

* Interactive Visualizations

  * Monthly Sales Trend
  * Revenue by Category
  * Order Status Distribution
  * Payment Method Analysis

* Dynamic Filters

  * Year
  * Category
  * Order Status
  * Country

## Tools & Skills Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Analysis
* Dashboard Design
* Data Visualization
* Excel Formulas

## Key Insights

* Track overall business performance through KPI metrics.
* Identify top-performing product categories.
* Analyze monthly sales patterns and trends.
* Evaluate order fulfillment efficiency.
* Understand customer payment preferences.

## Dataset

Amazon Sales Dataset (100,000+ records)
